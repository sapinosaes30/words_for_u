# You Are So Loved — for Bunbun

A personal, responsive static website made as a compliment corner for Andrea.

## Included
- Random compliment button and six compliment categories
- Compliment jar with a random note picker
- Reassuring notes for difficult days
- Four original mini-letters
- Save/remove favorites with browser `localStorage`
- Copy the current compliment
- Responsive mobile layout; no database or build step required

## Run locally
Open `index.html` in a browser.

## Deploy on Render
1. Create a GitHub repository and upload `index.html` and `README.md` from this folder.
2. In Render, choose **New + → Static Site** and connect the repository.
3. Leave **Build Command** blank and set **Publish Directory** to `.`.
4. Deploy. Render will publish the static site and can auto-deploy future GitHub changes.

Favorites are saved in the visitor's own browser, so they remain on that device/browser and are not shared between devices.
